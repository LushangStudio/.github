# LushangStudio 组织主页

本仓库用于 GitHub Organization [LushangStudio](https://github.com/LushangStudio) 的主页介绍。

GitHub 上的仓库名称必须为 `.github`，且仓库需为公开仓库。组织主页内容位于 [`profile/README.md`](profile/README.md)。本地文件夹名称不影响 GitHub 的显示。

## 内容来源

[微信公众号原文](https://mp.weixin.qq.com/s/7MRm-AEA4agS2U6XnTj8Gw)。按要求保留介绍内容，删除“如何加入”章节及文末成员介绍。

已根据保存的原文 HTML 整理为适合 GitHub 阅读的 Markdown，保留工作室介绍、成就、已有项目、正在推进的方向及工作条线，删除报名方式、招新时间与流程、文末成员介绍与寄语。原文中的项目数据与年份按原文保留。

## 发布

将本仓库推送到公开仓库 `LushangStudio/.github` 的默认分支后，GitHub 会在组织主页展示 `profile/README.md`。
